# JavaScript DOM and Events

Eight intermediate tasks that run in the browser: finding elements, changing text and styles, and handling click, input and submit events. Each task is an HTML page with its own JavaScript file.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.html](task1.html) + [task1.js](task1.js) | Welcome Page | `querySelector()`, `textContent` | Changes text and styles when the page loads |
| [task2.html](task2.html) + [task2.js](task2.js) | Theme Switcher | `classList.toggle()` | Toggles a dark theme and resizes text with buttons |
| [task3.html](task3.html) + [task3.js](task3.js) | Gate Counter | events + state | A counter with limits, driven by three buttons |
| [task4.html](task4.html) + [task4.js](task4.js) | SMS Character Counter | `input` event | Updates a character count on every key press |
| [task5.html](task5.html) + [task5.js](task5.js) | Fare Calculator | `value`, `checked` | Reads a select, a number and a checkbox to price a trip |
| [task6.html](task6.html) + [task6.js](task6.js) | Grade Checker Form | `submit`, `preventDefault()` | Validates a form and shows a grade |
| [task7.html](task7.html) + [task7.js](task7.js) | Class List Builder | `createElement()` | Adds and removes list items |
| [task8.html](task8.html) + [task8.js](task8.js) | Bookshop Cart | data to DOM | Draws products from an array and totals a cart |

## Shared stylesheet

All the pages link this shared stylesheet, so keep it in the same folder as the tasks.

- [style.css](style.css)

## What you should see

**Task 5: Fare Calculator**

Kasarani, 3 passengers, student ticked: *3 x KES 80 = KES 240*.

**Task 8: Bookshop Cart**

After adding two exercise books, a geometry set and a biro pen, the cart shows *Exercise book x2, Biro pen x1, Geometry set x1* and a total of KES 530.

## Run a task

Open `task1.html` in a web browser (double-click it, or drag it into Chrome or Edge). Keep each `.html` file next to its `.js` file.

Press F12 and open the Console tab to see messages and errors.
